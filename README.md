## 为什么支付宝付不了，问题卡在哪

Claude 官方对比页的支付选项一栏写得很明确：信用卡、ACH、发票/账期。这个限制在结账环节是硬性的，账单地区和卡组织类型过不了关，跟换浏览器、换设备没有关系。

国内的部分双币信用卡理论上能过，但能不能成功取决于发卡行和当时的风控，失败起来没什么规律，排查成本高。所以更多人直接换思路：用一张海外卡组织发行的美元虚拟卡去过官方的支付通道，充值来源用支付宝，两头各取所需。

## Max 5x 还是 Max 20x？

官方对两档的定义很简短：5x 适合“经常与 Claude 协作处理各种任务的用户”，20x 适合“大多数工作都和 Claude 一起做的每日重度用户”。翻译成可以直接对号入座的信号：

- 每周撞几次 Pro 的会话上限，日常任务不算特别重 → Max 5x 够用
- 每天跑数小时的 Claude Code 或 agent 长任务，或者 5x 的量经常不到重置就见底 → 直接上 Max 20x
- 拿不准 → 先买 5x。从低档升高档按剩余周期比例补差价、立即生效，猜错的成本很低；反过来降档要等当前计费周期结束才生效

还有一个容易被忽略的判断点：如果你需要的是团队共享工作区、SSO 和统一管理，Max 给不了，那是 Team 的领地。Max 买的是个人容量，不是管理功能。

## 买之前先搞懂用量规则

Max 的额度结构比“无限量”三个字复杂，下单前最好心里有数：

- **会话上限**：每 5 小时重置一次，5x 和 20x 的区别就在这个周期内的量
- **每周上限**：跨所有模型合计，在每周固定时间重置。重置时间由账户分配，不随你什么时候开始用、什么时候订阅而变化，每个周期都能拿到完整的周额度。Max 订阅下，Fable 模型有单独的每周限制
- **查看方式**：Settings > Usage 能看到当前消耗和下次重置时间
- **撞限之后的选项**：等重置、开通用量积分按标准 API 费率继续用，或者从 5x 升到 20x
- **保留条款**：Anthropic 保留追加限制的权利，包括额外的周/月上限，或针对特定模型和功能的用量限制

一句话概括：Max 是把桶换大了，桶的形状没变。它不是无限量套餐。

**从 Pro 年付转 Max 会亏吗？**
如果年付 Pro 的剩余价值高于 Max 价格，差额会转为账户余额抵扣未来订阅，但要求两次订阅的账单地址一致。地址变了的话，只能等 Pro 到期后用新地址重新订。

**支付一直被拒怎么办？**
按顺序查三样：卡内余额是否覆盖“订阅费+税费”、账单地址和开卡信息是否一致、扣款时网络环境是否稳定。三样都没问题还失败，换时间重试或联系发卡方。

**两三个人小团队，买几个 Max 还是上 Team？**
Max 没有共享工作区、集中计费和管理后台。超过一个人需要统一管理，Team 的标准席起点更低，管理功能也更全。
